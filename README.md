# 8 Week SQL Challenge

> A PostgreSQL portfolio featuring real-world business case studies covering restaurant analytics, delivery operations, subscription analytics, and banking analytics.

This repository contains my solutions to the **8 Week SQL Challenge**, a collection of SQL case studies created by Danny Ma.

The project focuses on solving realistic business problems using PostgreSQL and presenting each case study with clear documentation, structured SQL solutions, outputs, insights, and navigation.

---

## Project Objectives

Through these case studies, I aimed to strengthen my ability to:

- translate business questions into SQL queries,
- clean and transform real-world datasets,
- use joins, CTEs, subqueries, and window functions,
- perform customer, operational, and financial analysis,
- model recurring payments and running balances,
- and communicate findings clearly through structured documentation.

## Case Study Highlights

### 1. Danny's Diner

Analysed customer visits, spending patterns, popular menu items, membership behaviour, and loyalty-point calculations.

### 2. Pizza Runner

Cleaned inconsistent order data and analysed customer demand, runner delivery performance, pizza customisations, ingredients, pricing, and profitability.

### 3. Foodie-Fi

Explored subscription journeys, free-trial conversions, churn, upgrades, annual-plan adoption, and recurring payment generation.

### 4. Data Bank

Analysed customer-node allocation, financial transactions, monthly closing balances, running balances, percentiles, and alternative data-allocation models.

## Key Learning Outcomes

Completing these case studies strengthened my ability to:

- structure multi-step SQL analysis using CTEs,
- use window functions for ranking, transitions, running totals, and comparisons,
- handle inconsistent and non-standard data,
- apply business rules through SQL,
- validate query results against expected outputs,
- and present technical work in a clear, portfolio-ready format.
